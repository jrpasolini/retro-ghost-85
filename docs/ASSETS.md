# Media inventory and provenance

Original project media were preserved byte for byte during the release review. This inventory is a content/usage record, not a certification of third-party rights. See [notices](../THIRD_PARTY_NOTICES.md) and [credits](../CREDITS.md).

## Soundtrack

The maintainer confirmed that the six MP3 tracks were generated for the project using the music-creation tool on the ElevenLabs website. Generation-time model version, account plan and individual generation IDs were not established in this review; no model version is inferred from a later screenshot of the tool.

## Artwork

Artwork/portrait files were supplied as project media. The creation tool and individual source/likeness permissions were not established. The approved runtime board is `public/assets/board-reference-edited.webp`; it and the token/house geometry are unchanged. Original reference board and alternate cassette WebP are preserved in `docs/reference/` because the app does not load them. They are not copied into the frontend distribution.
