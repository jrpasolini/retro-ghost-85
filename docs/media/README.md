# Submission media

Assets used in the DEV submission post. They are documentation material: they are **not** part of the deployed build and are not linked from the site.

| File | What it is |
| --- | --- |
| `teaser-15s.mp4` | 15-second teaser, 1920x1080, H.264/AAC. Screen recording of the live game, cut to the game's own soundtrack (`public/audio/act-1.mp3`). The trophy dialog appears only as a short blurred flash so the narration reward is not spoiled. |
| `cover-1000x420.png` | Cover image for the post (1000x420, the size DEV expects). Frame from the opening reveal. |
| `screenshot-opening-16x9.png` | Opening screen with the "PRESS SPACE TO START" prompt. |
| `screenshot-board-16x9.png` | Board during the prologue, with the inspector panel open. |

## Provenance

The video and screenshots were captured by the project author on 2026-10-29 from the deployed build at `https://jrpasolini.tech/retro-ghost-85/`. The teaser audio is the project's own soundtrack, generated with ElevenLabs Music and already distributed with the game. No third-party footage appears in these files.

Titles and end cards in the teaser use **Press Start 2P** and **Chakra Petch**, both SIL OFL 1.1, the same fonts the game already ships.
